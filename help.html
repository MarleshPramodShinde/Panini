Panini V11 Technical Reference Manual

Welcome to Panini, a Sanskrit-based programming language built on an AST Kāraka Engine. Panini allows beginners and advanced developers to write structured, modular code using natural semantic cases.

1. Keyboard Shortcuts & Autocomplete

  • IntelliSense Autocomplete: Type letters like va, ya, or Sanskrit roots to open the auto-suggestion dropdown. Hit Enter to complete.
  • Run Code: Press Ctrl + Enter to compile and execute instantly.
  • Smart Keylogger: Typing English keywords followed by a space automatically converts them:
    • print → वद
    • scan / ask / pricha → पृच्छ
    • if → यदि | else → तर्हि
    • func / karya → कार्य
    • list / array → सूची[ ]

2. The Kāraka Destination Rule (-मध्ये)

Every memory assignment, mathematical result, or user input requires a target variable marked with the -मध्ये ("into") suffix.

१० आयु-मध्ये स्थापय      // Assigns 10 into 'आयु'
पृच्छ नाम-मध्ये          // Takes user input and saves into 'नाम'

3. Mathematical Operations

Math operations use a postfix structure: [Val1] [Val2] [Operator] [Target]-मध्ये

OperationCommandExample
Addition (+)संयोजय५ १० संयोजय योग-मध्ये
Subtraction (-)न्यूनय२० ५ न्यूनय शेष-मध्ये
Multiplication (*)गुणय४ ६ गुणय गुणन-मध्ये
Division (/)विभज१०० ५ विभज भाग-मध्ये
Remainder / Modulo (%)शेष१० ३ शेष उत्तर-मध्ये
Exponent / Power (^)घात२ ३ घात उत्तर-मध्ये

4. Conditionals & Loops

// If-Else Block
यदि ( अंक > १० ) {
    वद "Greater than 10"
} तर्हि {
    वद "10 or smaller"
}

// While Loop
यावत् ( चक्र > ० ) {
    वद चक्र
    चक्र १ न्यूनय चक्र-मध्ये
}

// For Loop (कृते)
कृते ( ० i-मध्ये स्थापय ; i < ५ ; i १ संयोजय i-मध्ये ) {
    वद i
}

5. Arrays & Collections V11 Feature

Panini supports standard indexed arrays with 0-based bracket access.

// 1. Initializing an Array
[ १०, २०, ३०, ४० ] संख्या-मध्ये स्थापय

// 2. Reading from an Index
वद संख्या[०]            // Outputs 10

// 3. Writing to an Index
९९ संख्या[१]-मध्ये स्थापय
वद संख्या[१]            // Outputs 99

6. User-Defined Functions V11 Feature

Functions are declared with कार्य and return values with प्रतिफल.

// Declare a function with parameters
कार्य वर्ग ( संख्या ) {
    संख्या संख्या गुणय उत्तर-मध्ये
    प्रतिफल उत्तर
}

// Call the function and store the returned value
वर्ग ( ५ ) परिणाम-मध्ये स्थापय
वद "Result: " परिणाम   // Outputs 25
